About TaskFlow

TaskFlow is a simple task management application designed to help users organize, track, and manage their daily activities efficiently.

Purpose

The application provides a simple interface for creating tasks, viewing task information, and monitoring task progress.

Usage Guide

  • Home page displays task summaries and navigation links.
  • Add Task page allows users to create new tasks.
  • Task List page displays all tasks and filter options.
  • Task Detail page shows complete information for a selected task.
  • Navigation links are available on every page for easy access.
